J.A.R.V.I.S. Handbuch

v2.1.1  ·  github.com/Black-Shadowcat/jarvis-voice-assistant
„Guten Tag. Womit kann ich Ihnen dienen?"

Dieses Handbuch begleitet dich von der Installation bis zum täglichen Einsatz — auch wenn du noch nie programmiert hast. Kein Fachwissen nötig. Claude Code erledigt die technische Arbeit für dich.

🔧 Was brauchst du?

Hardware & System
✓Mac mit macOS 14 oder neuer
✓Mikrofon (eingebaut oder extern)
⚡Smart Home (Home Assistant) — optional
Software (kostenlos)
✓Visual Studio Code
✓Google Chrome
✓Claude Code (Extension)
✓Homebrew (Paketmanager)
API Keys — was du vorab besorgen musst

API Keys sind wie Passwörter, die dir Zugang zu externen Diensten geben. Jarvis braucht zwei Pflicht-Keys — der Rest ist optional.

DienstWofürKostenPflicht
Anthropic Jarvis' Intelligenz (Claude Haiku KI) ~0,25 $ / 1 Mio. Wörter Ja
ElevenLabs Jarvis' Stimme (Text-to-Speech) ab ~5 $/Monat (Starter-Plan) Ja
Kachelmann Präzises lokales Wetter kostenpflichtig Optional
Home Assistant Lichtsteuerung, Kalender, Wetter Kostenlos (eigener Server) Optional
💡 Tipp Besorge die API Keys bevor du mit der Installation anfängst. Claude Code wird dich danach fragen und alles weitere automatisch einrichten.

📦 Schritt 1 — Visual Studio Code installieren

VS Code ist ein kostenloser Code-Editor von Microsoft. Du brauchst ihn als „Arbeitsumgebung" für Claude Code — auch wenn du selbst nichts programmierst.

VS Code herunterladen Gehe auf code.visualstudio.com und klicke auf den großen Download-Button für macOS.
Installieren Die heruntergeladene .zip Datei entpacken → Visual Studio Code.app in den Programme-Ordner ziehen.
VS Code starten VS Code öffnen. Beim ersten Start kann macOS nachfragen ob die App geöffnet werden darf → Öffnen klicken.

🤖 Schritt 2 — Claude Code einrichten

Claude Code ist der KI-Assistent der den Setup für dich übernimmt. Er läuft direkt in VS Code.

Claude Code Extension installieren

Extensions öffnen In VS Code links auf das Puzzle-Symbol klicken (oder Cmd + Shift + X).
Claude Code suchen In das Suchfeld Claude Code eingeben → Extension von Anthropic auswählen → Installieren klicken.
Anthropic Account erstellen Falls noch kein Account: claude.ai aufrufen → Registrieren. Danach mit demselben Account in Claude Code einloggen wenn gefragt.
Claude Code öffnen Nach der Installation erscheint Claude Code in der linken Sidebar. Klicke auf das Claude-Symbol und folge der Anmeldung.
✅ Fertig wenn: Du siehst in VS Code ein Chat-Feld wo du Claude Code Nachrichten schicken kannst.

📥 Schritt 3 — Jarvis herunterladen

Option A — ZIP Download (einfacher)
GitHub aufrufen github.com/Black-Shadowcat/jarvis-voice-assistant
Code → Download ZIP Grüner Button oben rechts → Download ZIP
Entpacken ZIP öffnen → Ordner z.B. nach ~/Dokumente/jarvis verschieben
Option B — Git (empfohlen für Updates)
Terminal öffnen Cmd + Leertaste → Terminal tippen → Enter
Klonen
git clone https://github.com/Black-Shadowcat/jarvis-voice-assistant.git

Ordner in VS Code öffnen

In VS Code: Datei → Ordner öffnen → den Jarvis-Ordner auswählen → Öffnen.

🔑 Schritt 4 — API Keys besorgen

Anthropic API Key (Pflicht)

console.anthropic.com aufrufen Mit deinem Anthropic-Account einloggen (derselbe wie für Claude Code).
API Keys → Create Key Links im Menü auf API Keys → Create Key → Namen vergeben → Key kopieren.
Key sicher aufbewahren Der Key beginnt mit sk-ant-. Er wird nur einmal angezeigt — irgendwo notieren!
⚠️ Guthaben aufladen Anthropic API Keys brauchen Prepaid-Guthaben. 5–10 € reichen für viele Monate normaler Nutzung. console.anthropic.com → Billing → Add Credits

ElevenLabs API Key & Voice ID (Pflicht)

elevenlabs.io aufrufen Account erstellen — für tägliche Nutzung wird der Starter-Plan benötigt (~5 $/Monat). Der Free-Plan reicht nicht aus.
API Key kopieren Oben rechts auf dein Profilbild → Profile + API Key → API Key kopieren (beginnt mit sk_).
Voice aussuchen Voice Library → Stimmen durchhören → eine wählen → Add to My Voices.
Voice ID kopieren My Voices → gewählte Stimme → unter dem Namen steht eine lange ID (z.B. rDmv3mOhK6TnhYWckFaD) → kopieren.
💡 Empfehlung Suche nach englischen Butler- oder Assistenten-Stimmen — die klingen als Jarvis am überzeugendsten. In der Config UI kannst du die Stimme später jederzeit ändern und vorhören.

Kachelmann Wetter API Key (Optional)

Gehe auf kachelmannwetter.com/api → Account erstellen → API Key im Dashboard kopieren. Der Zugang ist kostenpflichtig. Ohne diesen Key zeigt Jarvis kein Wetter in der Begrüßung.

Home Assistant (Optional)

Nur relevant wenn du Home Assistant für Smart Home nutzt. In HA: Profil → ganz nach unten scrollen → Long-Lived Access Tokens → Token erstellen. Die URL ist die lokale Adresse deines HA, z.B. http://10.0.0.10:8123.

✨ Schritt 5 — Setup mit Claude Code

Jetzt übernimmt Claude Code. Du musst nichts manuell konfigurieren.

Jarvis-Ordner in VS Code geöffnet? Stelle sicher dass VS Code den Jarvis-Ordner anzeigt (links im Explorer siehst du Dateien wie server.py, config.example.json etc.).
Claude Code öffnen Klicke links auf das Claude-Symbol oder drücke Cmd + Shift + C.
Setup starten Tippe genau das und drücke Enter:
Richte Jarvis ein
Claude Code liest die Setup-Anleitung und führt dich interaktiv durch alle Schritte.
Fragen beantworten Claude Code stellt dir eine Frage nach der anderen: Name, Anrede, Stadt, API Keys. Einfach antworten — Claude Code trägt alles ein.
Fertig! Nach etwa 5–10 Minuten ist alles eingerichtet. Claude Code sagt dir wenn der Setup abgeschlossen ist.
ℹ️ Was Claude Code automatisch erledigt Python 3.11 prüfen/installieren · alle Abhängigkeiten installieren · config.json erstellen und befüllen · voice.json anlegen · Autostart einrichten · Server testen

🚀 Schritt 6 — Jarvis starten

Nach dem Setup startet Jarvis über einen einzigen Tastendruck:

⌘ Cmd  +  ⇧ Shift  +  J
Startet Server, Chrome, Mic-Mute und alle konfigurierten Apps

Was beim Start passiert:

1.Der Jarvis-Server startet im Hintergrund
2.Chrome öffnet sich im App-Modus (ohne Adressleiste) — das ist das Jarvis HUD
3.Deine konfigurierten Programme öffnen sich
4.Jarvis begrüßt dich mit Wetter, Aufgaben und Kalender
✅ Autostart Nach dem ersten Setup startet Jarvis bei jedem Mac-Login automatisch. Du musst nichts manuell tun.

👋 Die Begrüßung

Jarvis begrüßt dich jedes Mal wenn er startet oder wenn du ihn aktivierst. Die Begrüßung enthält:

Was Jarvis sagt
🌤Aktuelles Wetter + Temperatur
📋Kurzübersicht deiner offenen Aufgaben
📅Heutige und morgige Termine
📬Anzahl ungelesener Mails
📝Hinweis auf offene Obsidian-Notizen
Manuell aktivieren

Sag jederzeit:

Du
Jarvis activate

Jarvis begrüßt dich neu mit aktuellen Daten.

💬 Erste Schritte — Mit Jarvis sprechen

Jarvis hört dauerhaft zu. Sprich einfach — du musst kein Aktivierungswort sagen (außer Jarvis activate für die Begrüßung). Sprich Deutsch, natürlich und in ganzen Sätzen.

Du
Wie wird das Wetter morgen?
Du
Suche nach den neuesten iPhone Preisen.
Du
Erinnere mich daran Mama anzurufen.
Du
Schalte das Licht im Wohnzimmer auf 40 Prozent.
💡 Hinweis zum Mikrofon Beim ersten Mal fragt Chrome nach der Mikrofon-Berechtigung — Zulassen klicken. Ohne Mikrofon-Zugriff kann Jarvis nicht zuhören.

🖥 Das HUD verstehen

Das HUD (Heads-Up Display) ist Jarvis' Oberfläche — ein dunkles Fenster ohne Browser-Leiste.

Der animierte Ring
● Gold Wartet auf dich (bereit)
● Blau Hört zu — sprich jetzt
● Orange Denkt nach…
● Grün Spricht gerade
● Rot Mikrofon stumm
Die vier Panels
oben linksJarvis HUD + Chat-Verlauf
oben rechtsDeine Programme (klickbar)
unten linksUngelesene Mails
unten rechtsOffene Aufgaben + Obsidian-Notizen

Mikrofon stummschalten

Klick auf den J.A.R.V.I.S. Ring im HUD → Mikrofon stumm (roter Ring). Nochmal klicken → wieder aktiv. Oder nutze den Mic-Mute-Button in der macOS Menüleiste.

Text eingeben statt sprechen

Klick auf das Stift-Symbol oben rechts im Jarvis-Panel → Textfeld erscheint → tippen + Enter.

⚙️ Einstellungen — Die Config UI

Alle Einstellungen lassen sich über die Config UI im Browser ändern — kein Programmieren nötig.

Config UI öffnen

Wenn Jarvis läuft, im Browser aufrufen: http://localhost:8340/config
Oder: Klick auf das Zahnrad-Symbol oben rechts im Jarvis HUD.

Was du einstellen kannst

BereichWas du ändern kannst
API Keys Anthropic und ElevenLabs Keys eintragen und testen. 👁 Auge-Symbol zeigt/versteckt den Key.
Stimme Aktive Stimme anzeigen, vorhören (▶ Preview) und über ⚙ Verwalten neue Stimmen hinzufügen.
Nutzer-Profil Deinen Namen, die Anrede durch Jarvis, deine Stadt und GPS-Koordinaten.
Home Assistant Schalter ein-/ausschalten, URL und Token eintragen.
Dienste & Pfade Kachelmann Key, Workspace-Pfad, Obsidian Inbox Pfad.
Begrüßung nach Standby Jarvis meldet sich automatisch wenn der Mac aus dem Schlaf aufwacht.
Programme Bis zu 6 Apps die beim Start mit geöffnet werden.
✅ Kein Neustart nötig Alle Einstellungen werden nach dem Speichern sofort wirksam — Jarvis läuft weiter.

🎙 Stimmen verwalten

Jarvis kann mehrere Stimmen kennen — du wechselst mit einem Klick zwischen ihnen.

Config UI öffnen http://localhost:8340/config (Jarvis muss laufen)
„⚙ Verwalten" klicken Im Bereich Aktive Stimme auf den Verwalten-Button klicken → Stimmen-Bibliothek öffnet sich.
Neue Stimme hinzufügen Name eingeben (z.B. „English Butler") → Voice ID von ElevenLabs einfügen → ▶ Testen → + Hinzufügen.
Stimme aktivieren Auf Aktivieren klicken → Jarvis spricht sofort mit der neuen Stimme.
ℹ️ Voice ID finden elevenlabs.io → My Voices → Stimme auswählen → die ID steht unter dem Namen (lange Zeichenfolge).

📱 Programme konfigurieren

Bis zu 6 Apps können beim Jarvis-Start automatisch geöffnet werden. Sie erscheinen auch als klickbare Schnellzugriffe im Programme-Panel.

Config UI öffnen → Programme-Bereich
App aus Dropdown wählen Alle auf deinem Mac installierten Apps werden angezeigt.
Speichern Beim nächsten Start öffnet Jarvis diese Apps automatisch.

🔧 Häufige Probleme

Jarvis antwortet gar nicht

Mögliche UrsacheLösung
Server läuft nichtCmd+Shift+J drücken um Jarvis neu zu starten
Anthropic API Key falsch/leerConfig UI → API Keys → Testen
Kein Guthaben bei Anthropicconsole.anthropic.com → Billing → Credits aufladen

Jarvis hört nicht zu (kein blauer Ring)

Mögliche UrsacheLösung
Mikrofon-Berechtigung fehltChrome fragt beim ersten Mal — Zulassen klicken
Mikrofon stummAuf den Ring klicken (roter Ring = stumm)
Falsches MikrofonmacOS Systemeinstellungen → Ton → Eingabe → richtiges Mikrofon wählen

Jarvis spricht nicht (keine Stimme)

Mögliche UrsacheLösung
ElevenLabs Key falschConfig UI → ElevenLabs Key → Testen
Voice ID fehltConfig UI → Stimme → Verwalten → Voice ID eintragen
Free-Plan aufgebrauchtelevenlabs.io → Usage prüfen

Kein Wetter in der Begrüßung

Kachelmann API Key fehlt oder ist falsch. Ohne Wetter-Key zeigt Jarvis kein Wetter. → Config UI → Kachelmann Key prüfen.

Mails / Aufgaben werden nicht angezeigt

macOS Berechtigungen prüfen: Systemeinstellungen → Datenschutz → Erinnerungen / Kontakte → Terminal oder Server erlauben.

Bildschirm-Feature funktioniert nicht

macOS Berechtigung: Systemeinstellungen → Datenschutz → Bildschirmaufnahme → Terminal hinzufügen.

Chrome öffnet sich nicht beim Start

Manuell starten: In VS Code → Claude Code → „Jarvis startet nicht, hilf mir" eintippen. Claude Code kennt das Problem und löst es.

💡 Tipps & Tricks

Jarvis neu starten

Cmd + Shift + J

Startet alles komplett neu falls etwas nicht reagiert.

Nur den Server neu starten

Config UI → Neu starten (roter Button) → Jarvis ist nach 10–15 Sekunden wieder da.

Was kostet das im Monat?

Bei normaler Nutzung (1–2 Stunden täglich sprechen):

Anthropic Claude Haiku1–3 € / Monat
ElevenLabs Starter~5 $ / Monat (für tägliche Nutzung nötig)
Kachelmann Wetterkostenpflichtig (optional)

Jarvis auf Englisch umstellen

Das Sprachmodell ist auf Deutsch konfiguriert. Willst du Jarvis auf Englisch oder eine andere Sprache umstellen, sprich Claude Code an: „Stelle Jarvis auf Englisch um".

Neue Funktion hinzufügen

Jarvis ist offen für Erweiterungen. Öffne VS Code, starte Claude Code und beschreibe was du möchtest — Claude Code setzt es um.

Hilfe bei Problemen

VS Code öffnen → Claude Code starten → Problem beschreiben. Claude Code kennt Jarvis und kann fast jeden Fehler beheben.

🎉 Du schaffst das! Jarvis ist dafür gemacht dass du ihn benutzt, nicht konfigurierst. Wenn etwas nicht klappt — Claude Code ist einen Satz entfernt.
